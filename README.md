This is a project I did for my university course to analyze the **Forbes 2000** list, which ranks the biggest public companies in the world.

The goal was to apply basic statistical concepts to understand how wealth is distributed among global corporations.

### 🔍 What I did
* **Data Cleaning:** Organized the raw dataset in Excel.
* **Statistical Analysis:** Calculated measures like Mean, Median, Standard Deviation, and Quartiles for variables such as *Sales, Profits, Assets,* and *Market Value*.
* **Inequality Study:** Used the **Gini Index** and Lorenz Curves to see the concentration of assets (checking if a few companies hold most of the money).
* **Correlations:** Analyzed the relationship between variables (e.g., *Do more Assets always mean more Profits?*).

### 💡 Key Findings
* **USA and China** dominate the list with the highest number of companies.
* The **Banking sector** holds the most assets, but Technology companies are often more profitable relative to their size.
* There is a high concentration of market value in the top 100 companies.

Este es un proyecto que realizamos para nuestra asignatura de la universidad para analizar la lista **Forbes 2000**, que clasifica las mayores empresas públicas del mundo.

El objetivo fue aplicar conceptos estadísticos básicos para entender cómo se distribuye la riqueza entre las corporaciones globales.

### 🔍 Qué hicimos
* **Limpieza de Datos:** Organizamos el dataset original en Excel.
* **Análisis Estadístico:** Calculamos medidas como la Media, Mediana, Desviación Típica y Cuartiles para variables como *Ventas, Beneficios, Activos* y *Valor de Mercado*.
* **Estudio de Desigualdad:** Usamos el **Índice de Gini** y Curvas de Lorenz para ver la concentración de activos (comprobando si pocas empresas acumulan la mayor parte del dinero).
* **Correlaciones:** Analizamos la relación entre variables (ej. *¿Tener más Activos significa siempre tener más Beneficios?*).

### 💡 Conclusiones Principales
* **EE.UU. y China** dominan la lista con el mayor número de empresas.
* El **sector Bancario** acumula la mayor cantidad de activos, pero las tecnológicas suelen ser más rentables en relación a su tamaño.
* Existe una alta concentración de valor de mercado en las top 100 empresas.
